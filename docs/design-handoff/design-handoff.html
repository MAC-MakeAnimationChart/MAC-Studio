MAC Studio 디자인 전달 문서

디자인 담당 팀원을 위한 정리입니다. 지금 서비스에 쓰이는 로고·로딩 애니메이션·색·글꼴·화면이 어디에 있고 어떻게 바꾸는지를 실제 파일 경로와 함께 적었습니다. 파일 경로는 저장소(mac-studio) 기준입니다.

1. 한눈에 보기2. 로고 파일3. 로딩 애니메이션 4. 색상5. 글꼴6. 화면 모음7. 고칠 때 보는 곳8. 확정이 필요한 것

1. 한눈에 보기

MAC Studio는 비전공자를 위한 노코드 차트 도구입니다. CSV·XLSX를 올리면 차트를 만들고 다듬어서 이미지로 내려받습니다. 유료 버전 MAC Expert는 별도 범위이고, 브랜드 방향만 정해 둔 상태입니다.
  • Studio(무료): 흰색 + 파랑 #2F66F5, 한 글자 느낌의 얇고 큰 제목(에스코어 드림 Light)
  • Expert(유료, 예정): 검정 #0B0B0F + 주황 #F97316
  • 라이트/다크 모드는 브라우저 설정을 따릅니다(처음 접속 시).
  • 화면은 데스크톱 기준으로 설계하고, 640px 미만에서 모바일 메뉴(≡)로 바뀝니다.

8. 아직 확정되지 않은 것 (디자인 확인 필요)

  • 차트 글꼴 목록: 지금은 임시 시스템 글꼴 10개입니다. 확정 목록이 나오면 lib/chart-fonts.ts만 교체합니다.
  • Expert 브랜딩: 검정 + 주황과 홈의 소개 섹션은 방향 제안입니다. 로고·세부 디자인은 아직 없습니다.
  • 광고 자리표시: 로딩 화면(336×250)과 로그인·회원가입 양옆(160×600)의 점선 박스는 임시이고, 광고 업체가 정해지면 교체합니다.
  • 푸터 사업자 정보 / 이용약관 / 개인정보처리방침: 값과 본문이 비어 있습니다(lib/company.ts, app/terms, app/privacy).
  • 25개 차트 모양: 28종 중 지금은 막대·선·원형만 구현되어 있고 나머지는 "준비 중"입니다. 차트 종류별 미리보기 그림은 구현되면 자동으로 생깁니다.
  • 로고 파일 정리: 헤더 마크(logo-mark.png)는 220×207이라 정사각형이 아닙니다. 필요하면 정사각 버전을 새로 받아 주세요.
