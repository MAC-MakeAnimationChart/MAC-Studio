    `lib/chart-data.ts`가 여러 계열을 돌려주게 하고, 옵션 패널에서 열을 여러 개 고르게 하고, 범례·색이 계열별로 나오게 합니다.
  - 건드릴 파일: `lib/chart-spec.ts`, `lib/chart-data.ts`, `components/chart-options-panel.tsx`, `components/charts/frame.tsx`(범례), `components/charts/types.ts`.
  - **주의:** 기존 막대·선·원형 차트가 그대로 동작해야 합니다(값 열 1개일 때 지금과 똑같이). 큰 작업이라 **계획을 먼저 받고 팀장에게 보여 주세요.**
  - 완료 기준: 값 열 1개일 땐 지금과 완전히 같고, 여러 개를 고르면 `supports.multiSeries`를 켠 차트에서만 보인다.

## 4단계. 기능 개선 (결정이 난 것부터)

- [ ] **4-1. 마이페이지에서 "새 차트 만들기" 흐름 바꾸기** ⭐⭐
  - 지금은 업로드 화면으로 가서 데이터셋을 바꿀 수 있는 문제가 있습니다.
  - 목표: 마이페이지 "새 차트 만들기" → **차트 유형만 고르는 모달** → 바로 `/studio/loading` → 편집. 폴더는 그대로 유지.
  - 건드릴 파일: `app/mypage/page.tsx`, `components/`(모달 새로), `lib/workspace.ts`.
  - 완료 기준: 새 차트가 항상 그 폴더 아래에 저장된다. 마이페이지에 "새 데이터셋 올리기"(기존 `/studio` 흐름)도 따로 있다.
- [ ] **4-2. 데이터셋 수정 시 저장 정책** ⭐⭐⭐ (팀 투표 결과 확정 후)
  - 같은 폴더에 다른 차트가 있는데 데이터를 바꿔서 저장하면 → "모든 차트에 반영 / 새 데이터셋으로 따로 저장" 모달.
    다른 차트가 없으면 그냥 저장. 데이터 수정이 걸려 있는 동안엔 자동 저장 건너뜀.
  - 건드릴 파일: `app/studio/editor/page.tsx`(`performSave`), `lib/saved.ts`.
  - 투표 결과가 다르면(항상 반영/항상 분리) 그에 맞게 단순화.
- [ ] **4-3. 같은 항목 묶기(집계) 옵션** ⭐⭐⭐ (필요하다고 결정되면)
  - 개인별 원본 데이터(성별 10,000행 같은)를 올리면 행마다 조각이 생깁니다. "같은 항목 묶기: 합계/평균/개수" 옵션을 추가.
  - 건드릴 파일: `lib/chart-spec.ts`, `lib/chart-data.ts`, `components/chart-options-panel.tsx`.
- [ ] **4-4. 데이터셋 표(DataGrid) 큰 파일 성능 확인** ⭐⭐
  - 3,000행 이상 CSV로 데이터셋 탭이 느리면 20행씩 페이지로 나눕니다(행 선택 목록 `RowPicker`와 같은 방식).
- [ ] **4-5. 글꼴 목록 확정판 적용** ⭐ — PO가 정한 약 10개로 `lib/chart-fonts.ts`의 목록만 교체.
- [ ] **4-6. 회원 용량 수치 확정** ⭐ — 확정되면 `lib/limits.ts`(업로드 5/10MB, 저장 30MB)만 수정. 홈 표와 마이페이지에 자동 반영.

## 6단계. 백엔드 연결 (백엔드 API가 나온 뒤)

명세는 백엔드 팀에 전달한 문서(소셜 로그인 API, 저장 API)를 기준으로 합니다.

- [ ] **6-1. 환경 설정**: `.env.local`에 `NEXT_PUBLIC_API_BASE`를 넣으면 가짜 서버 대신 실제 API를 부릅니다(`.env.example` 참고).
- [ ] **6-2. 소셜 로그인 키 연결**: 카카오/구글/네이버 콘솔에서 클라이언트 ID를 받아 `NEXT_PUBLIC_*_CLIENT_ID`에 넣고,
  콜백 주소 `https://도메인/auth/callback/{provider}`를 콘솔에 등록. (client secret은 백엔드만)
- [ ] **6-3. 세션 복원**: 앱이 열릴 때 `GET /me`로 로그인 상태를 확인하도록 `lib/auth.ts`를 바꿉니다.
- [ ] **6-4. 로그아웃·가입 API 연결**: `POST /auth/logout`, 이메일 가입·인증코드·로그인 API(`lib/email-verification.ts`, `components/auth-form.tsx`).
- [ ] **6-5. 저장 API 연결**: `lib/saved.ts`의 저장·불러오기·삭제를 데이터셋·차트 API로 교체. **바뀐 게 없으면 요청을 보내지 않는** 현재 규칙은 유지.
- [ ] **6-6. 저장 용량·한도를 서버 값(`GET /me`의 `limits`)으로 교체**.
